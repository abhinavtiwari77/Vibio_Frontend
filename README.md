VIBIO is a social networking platform frontend built using React, Vite, and Tailwind CSS, focused on delivering a seamless and engaging user experience. The application enables users to connect, share content, interact with communities, and communicate in real time.

The frontend includes a dynamic social feed, user profile pages, follow/unfollow functionality, post interactions through likes and comments, and community-based navigation. A real-time messaging interface was implemented using Socket.IO client integration, allowing users to exchange messages instantly without page refreshes.
