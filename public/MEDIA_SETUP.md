# Media Files Setup Guide

## Images (GIFs/Animated Backgrounds)

Place your animated GIF files in the `public/images/` folder with these names:

- `lofi-cafe.gif` - Lo-Fi Coffee Shop scene (like the screenshot you shared)
- `rainy-night.gif` - Rainy night scene
- `forest.gif` - Forest path scene
- `beach.gif` - Beach sunset scene
- `mountain.gif` - Mountain view scene

You can find free animated GIFs at:
- [Giphy](https://giphy.com/) - Search for "lofi", "rainy night", "forest", etc.
- [Tenor](https://tenor.com/)
- Create your own using tools like Adobe After Effects or online GIF makers

## Music Files

Place your MP3 files in the `public/sounds/` folder with these names:

- `peaceful-piano.mp3` - Calm piano music
- `lofi-beats.mp3` - Lo-fi hip hop beats
- `nature.mp3` - Nature sounds (rain, birds, etc.)
- `meditation.mp3` - Meditation/ambient music
- `jazz.mp3` - Smooth jazz café music

You can get royalty-free music from:
- [Free Music Archive](https://freemusicarchive.org/)
- [YouTube Audio Library](https://www.youtube.com/audiolibrary)
- [Pixabay Music](https://pixabay.com/music/)
- [Incompetech](https://incompetech.com/)

## Quick Setup

1. Download or create your GIFs and place them in `public/images/`
2. Download royalty-free music and place them in `public/sounds/`
3. Make sure file names match exactly as listed above
4. The app will automatically load and display them

## Tips

- Keep GIF file sizes under 5MB for better performance
- Use optimized GIFs (you can use tools like [ezgif.com](https://ezgif.com/) to compress)
- Music files should be in MP3 format, ideally 128-192 kbps quality
- Ensure all media files are properly licensed for your use

## Fallback

If media files are not found, placeholder content will be shown. The page will still function, but without the actual scenery animations and music.
